# Proyecto 01 — Agente de Limpieza Inteligente de Fotos (ALIF)

## Objetivo
Automatizar la clasificación y limpieza de fotos para reducir basura digital y optimizar almacenamiento en móvil y ordenador.

## Funciones del agente
- Detectar rostros
- Detectar capturas de pantalla
- Detectar imágenes borrosas
- Detectar duplicados
- Clasificar imágenes por categorías
- Aplicar reglas de eliminación o movimiento
- Generar reporte semanal

## Flujo conceptual
Trigger → Clasificación IA → Reglas → Acción → Log → Reporte

## Impacto esperado
- Ahorro de tiempo
- Reducción de memoria ocupada
- Organización automática
- Menos tareas repetitivas
