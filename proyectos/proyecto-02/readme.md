# Proyecto 02 — Copiloto de Reporting Aumentado (CRA)

## Objetivo
Construir un copiloto que genere reportes automáticos, resúmenes ejecutivos e insights basados en datos estructurados y no estructurados.

## Problema que resuelve
Los equipos dedican tiempo a:
- preparar reportes,
- interpretar datos,
- resumir información,
- detectar patrones,
- redactar conclusiones.

CRA automatiza estas tareas.

## Funciones principales
- Generación automática de reportes.
- Resumen de información clave.
- Interpretación de datos.
- Detección de patrones y anomalías.
- Insights accionables.
- Exportación de reportes.

## Impacto esperado
- Ahorro de tiempo.
- Mayor claridad en decisiones.
- Reportes consistentes.
- Reducción de errores humanos.
