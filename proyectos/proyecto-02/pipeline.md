# Pipeline Completo — Proyecto 02 (CRA)

## 1. Entrada del sistema
El sistema recibe:
- Archivos CSV o Excel.
- Documentos PDF o TXT.
- Parámetros del usuario (fechas, métricas, tipo de reporte).
- Preguntas específicas sobre los datos.

---

## 2. Preprocesamiento
Acciones:
- Validación del archivo.
- Limpieza básica (columnas vacías, tipos de datos).
- Normalización de nombres de columnas.
- Conversión a estructura interna (DataFrame).

---

## 3. Procesamiento analítico
El sistema calcula:
- Métricas descriptivas (totales, medias, máximos, mínimos).
- Tendencias temporales.
- Comparaciones entre periodos.
- Patrones relevantes.
- Anomalías (valores fuera de rango).

---

## 4. Interpretación con IA
El motor de interpretación:
- Resume los hallazgos.
- Explica tendencias.
- Destaca anomalías.
- Genera insights accionables.
- Adapta el lenguaje según el tipo de usuario.

---

## 5. Generación del reporte
El sistema construye:
- Resumen ejecutivo.
- Sección de métricas clave.
- Sección de insights.
- Conclusiones.
- Recomendaciones.

Formato:
- Texto estructurado.
- Lenguaje profesional.
- Secciones claras.

---

## 6. Salida del sistema
El usuario recibe:
- Reporte completo.
- Resumen ejecutivo.
- Insights clave.
- Respuestas a preguntas específicas.
- Exportación del reporte (texto).

---

## 7. Registro y trazabilidad
El sistema guarda:
- Fecha de ejecución.
- Tipo de reporte.
- Datos analizados.
- Resultados generados.
- Insights detectados.

---

## 8. Flujo completo
Entrada → Preprocesamiento → Procesamiento → Interpretación → Reporte → Salida → Log
