# Pipeline Completo — Proyecto 03 (AORA)

## 1. Entrada del sistema
El agente recibe:
- Documentos (PDF, TXT, DOCX).
- Correos o textos.
- Solicitudes del usuario (resumen, tareas, ejecución).
- Parámetros operativos (prioridad, tipo de acción).

---

## 2. Preprocesamiento
Acciones:
- Validación del archivo o texto.
- Extracción de contenido.
- Limpieza de texto.
- Conversión a estructura interna.

---

## 3. Resumen automático
El sistema:
- Genera un resumen ejecutivo.
- Identifica puntos clave.
- Reduce ruido.
- Detecta información relevante.

---

## 4. Detección de tareas
El agente:
- Identifica acciones explícitas.
- Detecta tareas implícitas.
- Clasifica por prioridad.
- Asigna categoría (operativa, administrativa, técnica).
- Identifica dependencias.

---

## 5. Ejecución automática
El motor de acción:
- Ejecuta tareas simples:
  - mover archivos,
  - generar reportes,
  - crear notas,
  - registrar tareas,
  - actualizar panel.
- Solicita confirmación para tareas críticas.
- Marca tareas como completadas.
- Registra resultados.

---

## 6. Generación del reporte operativo
El sistema produce:
- Resumen del documento.
- Tareas detectadas.
- Acciones ejecutadas.
- Tareas pendientes.
- Conclusiones operativas.

---

## 7. Salida del sistema
El usuario recibe:
- Resumen.
- Lista de tareas.
- Acciones realizadas.
- Reporte operativo.
- Registro de actividad.

---

## 8. Registro y trazabilidad
El sistema guarda:
- Fecha de ejecución.
- Documento procesado.
- Tareas detectadas.
- Acciones ejecutadas.
- Resultados.
- Logs completos.

---

## 9. Flujo completo
Entrada → Preprocesamiento → Resumen → Tareas → Acción → Reporte → Salida → Log
